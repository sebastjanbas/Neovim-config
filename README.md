# nvim

My personal Neovim config — lazy.nvim managed, Catppuccin themed, with LSP, Treesitter, Snacks, Trouble, and Telescope for a fast, modern editing setup.

### UI & Appearance

| Plugin | Description |
| --- | --- |
| [catppuccin/nvim](https://github.com/catppuccin/nvim) | Soothing pastel colorscheme |
| [nvim-lualine/lualine.nvim](https://github.com/nvim-lualine/lualine.nvim) | Statusline |
| [goolord/alpha-nvim](https://github.com/goolord/alpha-nvim) | Startup dashboard |
| [folke/which-key.nvim](https://github.com/folke/which-key.nvim) | Keybinding hints popup |
| [NvChad/nvim-colorizer.lua](https://github.com/NvChad/nvim-colorizer.lua) | Inline color highlighting |
| [eero-lehtinen/oklch-color-picker.nvim](https://github.com/eero-lehtinen/oklch-color-picker.nvim) | OKLCH color picker |
